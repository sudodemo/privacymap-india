# PrivacyMap India — Knowledge Base

This directory is the versioned knowledge/intelligence layer for the Next.js PrivacyMap India application.

## V1.6 contents

- `core/` — generic assessment vocabularies, processes, roles, storage, retention, security and risk rules.
- `legal/` — DPDP Act/Rules reference mappings, controls, sources and commencement intelligence.
- `sectors/education/school/` — the existing Education/School data-entry-point and field catalogue from V1.6.
- `CHANGELOG.json` and `RELEASE_MANIFEST.json` — release governance metadata.

## Privacy architecture

The knowledge base contains no customer assessment responses. Assessment responses should remain client-side in the browser unless a future release explicitly introduces a storage service.

## Legal status

Legal content is reference mapping only. Always evaluate the relevant provision/rule using its effective date and current official source. Do not display a blanket "DPDP compliant" conclusion.

## Source hierarchy

1. Official Gazette / notification
2. India Code
3. MeitY official Rules and notifications
4. Secondary sources only for discovery
